# craft. — portfolio

Independent portfolio site rebuilt with [Astro](https://astro.build) + Tailwind CSS 4.

## Commands

```sh
npm install      # install deps
npm run dev      # start dev server
npm run build    # static build to dist/
npm run preview  # preview the build
npm run typecheck
npm run lint
```

## Stack

- **Astro 7** — static-first, zero framework JS shipped
- **Tailwind CSS 4** — CSS-first config (`@theme` in `src/styles/global.css`)
- **Lenis** — smooth scroll (vanilla, in `src/layouts/Base.astro`)
- **Canvas 2D** — interactive ASCII block-wave hero (`src/scripts/pixel-wave.ts`)
